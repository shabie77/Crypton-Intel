3. Powell/Fed Tone Analysis (Manual Update)

🏦 What It Does

Tracks Federal Reserve's stance on interest rates and inflation. One of the biggest drivers of crypto prices.

How It Works:

You manually assess Fed statements/speeches and update:

  • Dovish (1-2/5): "Rates will stay low, Fed patient" → Bullish for crypto
  • Neutral (3/5): "Monitoring inflation carefully" → Mixed signals
  • Hawkish (4-5/5): "Rate hikes coming, fighting inflation" → Bearish for crypto

Update via Bot Command (No Code Changes):

/update_powell dovish 2 "Fed signals patient approach to rates" ✅ Updated successfully

Appears in Morning Digest as:

🏦 Fed Stance (Last Updated: 2025-04-03) Powell Tone: DOVISH (2/5 hawkish) Context: "Fed signals patient approach to rate hikes" Impact: 🟢 Positive for crypto

4. Multi-Timeframe RSI Extreme Alerts (Real-Time)

📈 What It Does

Monitors RSI on 4-Hour, Daily, and Weekly charts. Alerts when extreme conditions (overbought/oversold) are detected WITH volume confirmation.

Alert Conditions:

  • 4-Hour Chart: RSI > 75 OR RSI < 25 + volume confirmation → 🟡 MODERATE IMPACT
  • Daily Chart: RSI > 75 OR RSI < 25 + volume confirmation → 🟠 HIGH IMPACT
  • Weekly Chart: RSI > 75 OR RSI < 25 + volume confirmation → 🔴 VERY HIGH IMPACT

Volume Confirmation Rule:

Only trigger if:

  • RSI is extreme AND
  • Trading volume is 15%+ above 20-day average

This filters out fake signals. Prevents alert fatigue.

Alert Example:

🔴 RSI EXTREME - Daily Chart 📊 BTC/USDT RSI: 23 (Oversold) Volume: +25% above average ⏰ Timeframe: Daily (4H: 35, 1W: pending) 💡 Analysis: Strong oversold bounce potential ⚠️ Cooldown: Next alert in 6+ hours

Data Source:

Binance REST API (Free tier) - Zero cost, real-time candlestick data

FREE Real-time HIGH PRIORITY

⚠️ Risks & Mitigation

Risk 1: Web Scraper Fragility

🔴 Risk:

Forex Factory or CoinGlass changes HTML structure → scraper breaks

✅ Mitigation:

  • Use try/catch error handling around all scrapers
  • Implement fallback sources (2-3 backup calendars)
  • Set up error alerts: "Macro calendar scraper failed, using backup"
  • Monitor logs daily in testing phase

Risk 2: False Signals (RSI)

🔴 Risk:

RSI extreme doesn't always mean reversal (can stay overbought for weeks)

✅ Mitigation:

  • Volume confirmation: Only alert if volume is 15%+ above average (already built in)
  • Alert cooldown: Max 1 alert per coin per 6 hours (prevents spam)
  • Track accuracy weekly. If below 50%, disable RSI alerts and refine logic
  • Always include disclaimer: "This is analysis, not financial advice"

Risk 3: API Rate Limits

🔴 Risk:

Binance API might rate limit if checking too frequently

✅ Mitigation:

  • Stagger requests: Don't check 10 coins simultaneously
  • Use exponential backoff for retries
  • Binance free tier allows 1200 requests/minute (plenty for this bot)

Risk 4: Bot Crashes on Railway

🔴 Risk:

Long-running bot can accumulate memory leaks or crash

✅ Mitigation:

  • Set Railway to auto-restart on crash (check Railway settings)
  • Monitor memory usage in logs daily
  • Schedule weekly restart at low-traffic time
  • Use try/catch around all long-running loops

Risk 5: Telegram Bot Getting Banned

🔴 Risk:

Spammy alerts → Telegram limits bot for abuse

✅ Mitigation:

  • Alert cooldown: Max 1 alert per coin per 6 hours
  • Morning digest = 1 message per day (good)
  • Real-time alerts = only when meaningful (macro events, extreme RSI)
  • Monitor Telegram bot settings for warnings
